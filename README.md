# Капитал — денежный кликер

Нативная Android-игра: тайкун-кликер про путь от курьера до триллионера.
Kotlin + Jetpack Compose (Material 3) + Room.

## Как получить APK

Бинарник `gradle-wrapper.jar` в репозитории отсутствует намеренно, а `./gradlew` —
скрипт-заглушка, который сам по себе не собирает. Самый простой путь:

1. Открыть папку Capital в Android Studio (Hedgehog или новее).
2. Дождаться синхронизации Gradle — IDE сама подтянет wrapper и зависимости.
3. Build > Build App Bundle(s) / APK(s) > Build APK(s).
   Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.
4. Либо нажать Run и поставить на устройство или эмулятор.

Для сборки из терминала сначала сгенерируйте wrapper командой `gradle wrapper`
(нужен установленный Gradle 8.9), затем `./gradlew assembleDebug`.

`local.properties` (не под контролем версий) должен указывать `sdk.dir` на Android SDK.

## Архитектура

Три слоя в `app/src/main/java/ru/capital/idle/`:

- **core/game** — вся игровая логика без зависимостей от Android.
  `GameState` — единое иммутабельное состояние всего прогресса; `GameMath` —
  чистые функции всей экономики (доход в день, зарплата, оффлайн-доход,
  множители, форматирование); `GameConfig` — константы баланса. Контент вынесен
  в самодостаточные модули: `Economy` (время, сон, работа, отрасли, образование,
  окружение, фазы рынка, управляющие), `Investments` (вклады и биржа),
  `Prestige` (перерождение и слитки), `Lifestyle` (жильё/авто/техника, хроника,
  музей), `Milestones`, `Onboarding`, `RankModel`/`RankingData`, `CardTier`,
  `Currency`.
- **data** — хранение прогресса. Источник истины — JSON-файл `save.json` во
  внутреннем хранилище (`GameRepository`/`SaveFile`), устойчивый к сменам схемы БД.
  Room (`GameEntity`, `GameDao`, `AppDatabase`) используется как вторичный кэш и
  пересоздаётся при обновлении версии (`fallbackToDestructiveMigration`), поэтому
  обновления игры не обнуляют прогресс.
- **ui** — `GameViewModel` (единый владелец состояния, `StateFlow<GameState>`,
  игровой цикл на корутине с тиком 100 мс, автосейв каждые 30 секунд и при
  сворачивании, начисление оффлайн-дохода при возврате), экраны на Compose
  (`GameScreen`, `InvestScreen`, `WorldScreen`, `DevScreen`, `ProfileScreen`,
  `PrestigeScreen` и др.) и тема (`ui/theme`, glass-стиль).

## Игровой цикл

Тап даёт деньги вручную; наёмная работа и предприятия по отраслям приносят доход;
образование открывает вакансии и уровни отраслей; вклады и биржа наращивают
капитал; стиль жизни и репутация влияют на множители; перерождение обнуляет
прогресс ради золотых слитков, которые навсегда усиливают доход. Игровое время
сжато: 1 игровой час = 1 секунда реального. При возврате в игру начисляется
оффлайн-доход (с затуханием и потолком по времени).

`GameMath`/`Economy`.
